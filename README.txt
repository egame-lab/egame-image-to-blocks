用途
----
將圖片轉換為可以貼進 E-game 達克武館的 Blockly 積木 XML。

啟動
----
解壓縮 ZIP 後以 Chrome 或 Edge 開啟 index.html（無需安裝套件）。
請保留 index.html、styles.css、script.js、pixel-editor.js、
background-cleaner.js、ui.js、quick-ui.js、game-ui.js 在同一資料夾。

快速轉換（預設）
----------------
1. 點「選擇圖片」、按 Ctrl+V 貼上，或將圖片拖到上傳區。
2. 選擇「完整保留」或「拉伸填滿」。
3. 選擇標準積木 80×80，或內建擴充積木的尺寸與色彩。
4. 按「預覽積木效果」，可以查看轉換後的預覽。
5. 確認後按「複製積木碼」；懂 XML 的使用者可展開「查看積木程式碼（XML）」。
快速模式更換圖片時會先詢問是否取代現有內容（可 Ctrl+Z 復原）。

進階編輯
--------
點上方「進階編輯」，可使用貼圖、繪圖圖層、獨立裁切、自由縮放等功能。
「原始畫布」是預設的繪圖層，移動圖片與畫筆內容各自可以調整圖層順序。
「新增繪圖圖層」才會產生另一個獨立的繪圖層；可隱藏、上移、下移或刪除。
選取貼圖後按「編輯圖片像素」或鉛筆／橡皮擦，即可直接改這張貼圖；不必先合併。
右側工具設定展開後，底部預覽按鈕會留在視窗底部，不必捲到最下方。
圖片尺寸及加入設定在畫布下方，貼圖調整列位於工作區上方；預設自由拉伸。

限制與注意事項
--------------
- 本版仍為介面實驗版；分層專案還無法保存並於下次開啟後還原。
- 若瀏覽器限制剪貼簿讀取，請直接在網頁按 Ctrl+V，
  或改用「選擇圖片」。部分瀏覽器需要 HTTPS／localhost 才支援進階剪貼簿 API。
- 高解析度圖片會依編輯器安全上限縮小顯示畫布，原圖仍保存在圖層來源中。
- 全部官方背景、角色、遊戲商標與其他遊戲素材均未包含在本檔案內。
