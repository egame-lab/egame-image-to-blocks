積木匯入指南

如何貼到 E-game 武館？

本網站可以產生 XML 積木碼，但原本武館沒有直接貼上積木碼的按鈕。請選擇一種匯入方式。

推薦 E-game 積木工具（精簡版） 提供積木複製、貼上及加速功能，其中加速功能經改進後有更快的執行速度
其他選擇 E-game Tools 完整工具包 Hello Bug（wangicheng）開發，提供更多武館輔助功能，但部分功能目前已失效
  1. 選擇上方其中一款工具，依照 GitHub 的說明安裝並啟用。
  2. 在本網站完成預覽，按「複製積木碼」。
  3. 開啟 E-game 武館的積木編輯畫面，點擊工具提供的「貼上」按鈕。
  4. 貼上後可按「執行」或「加速」繪圖，確認結果後再儲存武館。

工具需另行安裝。標準積木的繪圖指令較多，建議使用「加速」功能。Ctrl+V 可在本網站貼上圖片，但無法直接將積木碼貼進原版武館。

  1. 先在本網站按「預覽積木效果」，產生積木碼。
  2. 按下方「複製匯入指令」。指令會包含這次的積木，不必重新複製積木碼。
  3. 開啟武館積木編輯畫面，按 F12，選擇 Console（控制台）。
  4. 按 Ctrl + V 貼上，再按 Enter 執行。
  5. 確認積木出現後儲存。建議先在空白工作區使用，避免重複匯入。

程式不會讀取剪貼簿；它直接包含目前產生的積木資料。瀏覽器可能阻止貼上指令，請只執行自己信任的程式。

  1. 在 Chrome 網址列輸入 chrome://bookmarks/，開啟書籤管理員。
  2. 新增書籤：名稱填「貼上武館積木」，網址填入下方複製的書籤程式。
  3. 以後只要在本網站按「複製積木碼」，回到武館積木編輯頁面，點這個書籤。
  4. 若無法自動讀取剪貼簿，依提示手動貼上積木碼；成功後記得儲存。

Android Chrome：先將網頁加入書籤，編輯該書籤的網址為下方提供的程式。使用時在武館頁面的網址列輸入書籤名稱，從建議清單點選它執行；直接從書籤清單打開不一定能執行。

首次使用時，瀏覽器可能要求允許讀取剪貼簿。若無法自動貼上，可以依照提示手動貼上積木碼。

完成積木預覽後，即可複製需要的內容。

標準積木使用武館積木包中的積木，但複雜圖片可能執行緩慢；內建擴充積木包使用遊戲已實作但武館積木包未提供的積木類型。三種方式皆單純加入積木，不自動儲存。
