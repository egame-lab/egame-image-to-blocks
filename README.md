# 像素積木工坊 — E-game 圖片轉積木

E-game 達克武館圖片編輯與積木轉換工具，可直接在瀏覽器中使用。

## 主要功能

- **快速轉換**：匯入圖片、預覽積木效果、複製積木碼。
- **進階編輯**：畫筆、橡皮擦、圖案、圖片調整、圖層與復原重做。
- **輸出模式**：標準積木（80×80、70 色）及內建擴充積木（提供更多解析度與色彩選項）。
- **匯入指南**：介紹工具包、控制台與書籤方式將積木貼到武館。

## 使用方式

開啟網站的 `index.html`，或將整個專案部署到 GitHub Pages 使用。請將 HTML、CSS、JavaScript 檔案放在同一資料夾。

1. 加入圖片，必要時進入「進階編輯」調整。
2. 選擇積木模式，按「預覽積木效果」。
3. 按「複製積木碼」，再點「如何貼到武館？」查看匯入方式。

原版武館沒有直接貼上積木碼的功能，推薦搭配 [E-game 積木工具（精簡版）](https://github.com/egame-lab/egame-copy-paste)；需要更多功能時，也可參考 [Hello Bug 的 E-game Tools 完整工具包](https://github.com/wangicheng/egame-tools)，但其中部分功能目前已失效。標準積木可能產生大量繪圖指令，建議搭配加速功能。

若使用免安裝書籤，先建立名稱為 `eg` 的 JavaScript 書籤；之後在本網站複製積木碼，切回武館執行書籤即可。Android Chrome 從網址列搜尋 `eg` 並選擇書籤；iPhone Chrome／Safari 從書籤清單開啟。

## 使用聲明

本工具為非官方 E-game 輔助工具，僅供圖片編輯及積木轉換，請遵守遊戲內的武館規範，勿用於製作或發布不雅、侮辱、騷擾等不當內容。武館作品及發布行為由使用者自行負責，應謹慎使用工具；遊戲或瀏覽器更新可能影響工具部分功能。

工具依現況提供，不一定能相容所有 E-game 版本及瀏覽器。下載的 PNG 保存合成圖片，暫不支援保存可重新編輯的分層工程。

## 手機版支援

網站已針對手機調整，手機積木匯入支援 Android Chrome、iPhone Chrome 與 Safari，透過 JavaScript 書籤將 XML 積木碼貼入武館。

- **首次設定：** 建立名稱為 `eg` 的書籤，將網址替換為網站提供的書籤程式。
- **日常使用：** 複製積木碼 → 開啟武館 → 執行書籤 → 貼上 XML。
- **啟動方式：** Android Chrome 從網址列搜尋 `eg` 並選取書籤；iPhone Chrome 與 Safari 可從書籤清單直接開啟。

貼上視窗支援長篇 XML、自動驗證及匯入，並檢查積木容量與新增數量。匯入成功後自動關閉；部分瀏覽器可直接讀取剪貼簿。

**注意：** E-game 原站未針對手機操作完整最佳化，尤其 iPhone 裝置介面排版有問題。積木編輯、工作區縮放及大量積木的執行效能較受限。
