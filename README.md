# 像素積木工坊 — E-game 圖片轉積木

E-game 達克武館圖片編輯與積木轉換工具，可直接在瀏覽器中使用。

## 主要功能

- **快速轉換**：匯入圖片、預覽積木效果、複製積木碼。
- **進階編輯**：畫筆、橡皮擦、圖案、圖片調整、圖層與復原重做。
- **輸出模式**：標準積木（80×80、70 色）及內建擴充積木（提供更多解析度與色彩選項）。
- **匯入指南**：介紹工具包、控制台與書籤方式將積木貼到武館。

## 使用方式

開啟網站的 `index.html`，或將整個專案部署到 GitHub Pages 使用。請將 HTML、CSS、JavaScript 檔案放在同一資料夾。

1. 加入圖片，必要時進入「進階編輯」調整。
2. 選擇積木模式，按「預覽積木效果」。
3. 按「複製積木碼」，再點「如何貼到武館？」查看匯入方式。

原版武館沒有直接貼上積木碼的功能，推薦搭配 [E-game 積木工具（精簡版）](https://github.com/qert15376-code/egame-copy-paste)；需要更多功能時，也可參考 [Hello Bug 的 E-game Tools 完整工具包](https://github.com/wangicheng/egame-tools)，但其中部分功能目前已失效。標準積木可能產生大量繪圖指令，建議搭配加速功能。

## 使用聲明

本工具為非官方 E-game 輔助工具，僅供圖片編輯及積木轉換，請遵守遊戲內的武館規範，勿用於製作或發布不雅、侮辱、騷擾等不當內容。武館作品及發布行為由使用者自行負責，應謹慎使用工具；遊戲或瀏覽器更新可能影響工具部分功能。

工具依現況提供，不一定能相容所有 E-game 版本及瀏覽器。下載的 PNG 保存合成圖片，暫不支援保存可重新編輯的分層工程。

## 手機版捲動（v0.10.10）

手機版採用穩定的畫布高度，避免瀏覽器網址列收合造成畫布及內容上下位移；只有螢幕寬度真正改變時才重新執行「符合視窗」。一般頁面捲動不會觸發多餘的積木預覽狀態計算。

## 手機貼上 XML（v0.10.11）

修正 Android Chrome 原生 `prompt()` 在長篇積木碼測試時，輸入於第 5,000 字元處截斷的問題。新版一鍵貼上書籤改為在 E-game 武館頁面建立多行貼上視窗。使用者可以在手機直接貼上 XML，匯入前先檢查 XML 完整性及剩餘積木容量，匯入後比較預期與實際新增積木數。需在 Chrome 書籤中重新貼入網站產生的新版書籤程式。

## 手機快速貼上（v0.10.12）

在 Chrome Android 中，將 JavaScript 書籤取簡短名稱（例如 `eg`），在 E-game 頁面的網址列輸入並點擊書籤搜尋建議。新版匯入視窗提供「從剪貼簿匯入」按鈕（取決於瀏覽器剪貼簿權限）；若不可用，長按文字框貼上也會自動驗證並匯入。完成且積木數相符後視窗自動關閉，顯示短暫通知提醒儲存；不完整或不相符時保留視窗說明原因。網站匯入指南的「複製積木碼」成功後也會自動收合並顯示提示。

如要免去 Chrome Android 的網址列搜尋步驟，需要使用支援擴充功能或使用者腳本的瀏覽器；原生 Chrome 目前無法讓一般網頁直接修改另一個網域的 Blockly 工作區。
